# SCORPION-7 — рабочий стол сотрудника (сайт)

**Как открыть:** откройте `index.html` в браузере. Страница самодостаточная: все картинки и звук встроены в неё, интернет не нужен.

## Что внутри
- `index.html` — сам сайт.
- `assets/images/` — все картинки, использованные на сайте (камеры в разное время суток, карта судна, портреты администраторов, логотипы, фото).
- `assets/audio/` — запись `sequence_06` (mp3 для сайта и оригинальный wav).
- `content/` — все тексты сайта в формате Markdown: личные дела, реестр группы, администрация, внутренние документы, почта, журнал тревог, камеры, расположение ярлыков.
- `originals/` — исходные файлы, которые вы присылали (в полном размере, без обработки).

## Примечания
- Погода на камерах моделируется кодом и меняется каждые 3 часа; кадр камеры выбирается по местному времени посетителя.
- Файл `page_4_side_A.wav` на сайте намеренно не проигрывается (выдаёт ошибку); отдельного аудиофайла у него нет.
- В `index.html` встроены ещё несколько обработанных версий картинок; в `assets/images/` лежат те же файлы отдельно.
